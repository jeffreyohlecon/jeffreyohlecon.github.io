# Jeffrey W. Ohl academic website

This repository publishes the academic website for Jeffrey W. Ohl.

## Update the site

- Edit `app/page.tsx` to change the introduction, papers, or links.
- Replace `public/jeffrey-ohl.jpg` to update the portrait.
- Edit `app/cv/page.tsx` if the public CV link changes.
- Push changes to `main`. GitHub Pages publishes them automatically.

## Preview changes

Install Node.js 22, then run:

```sh
npm install
npm run dev
```

Open `http://localhost:3000`.

## Custom domain

The repository intentionally has no `CNAME` file yet. Add the custom domain
only after the proposed DNS changes have been reviewed and approved.
